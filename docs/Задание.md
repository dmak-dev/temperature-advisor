## Вариант 17. Подбор температуры в помещении

### Сценарий:

Пользователь вводит тип помещения и текущий сезон.
Сервис должен рекомендовать оптимальную температуру.
Для разных помещений используются разные температурные нормы.

Внутренняя логика:

1. TemperatureAdvisor (абстрактный класс)
2. OfficeTemperature
3. HomeTemperature
4. WarehouseTemperature

Пример:

1. office: комфортная рабочая температура
2. home: бытовая температура
3. warehouse: пониженные значения

Пример входных данных:

```python
{
  "room_type": "office",
  "season": "winter"
}
```

Пример выходных данных:

```python
{
  "recommended_temperature": 22,
  "season": "winter"
}
```

Что необходимо реализовать:

1. Написать эндпоинт.
2. Прописать входные и выходные данные через типизированные словари.
3. Написать интерфейс, в который отправляются данные из эндпоинта.
4. Описать схему и валидировать данные.
5. Обрабатывать ошибки 400 и 500.
6. Создать собственное исключение.
